# رادار المتاجر — منصة متاجر متعددة

منصة يفتح فيها كل تاجر متجره باسمه ورمزه، ويتدير كل شيء من لوحته:
منتجات، طلبيات وتوصيل، أرصدة زبائن، عروض، لافتة، ورمز QR لكل متجر.

## صفحة إدارة المنصة
من داخل التطبيق: ٥ ضغطات على عنوان «المتاجر» في الشاشة الأولى — برمز المنصة.

## التشغيل
    npm install
    npm start
